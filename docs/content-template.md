## 書き方のルール

- 読み手：野球をまったく観たことがない、ルールもほとんど知らない大人。球場の待ち時間に、スマホで1〜2分で読む
- 長さ：level 1 は 500〜1000字、level 2 は 250〜600字。わかりやすさのためなら長くなってよい（ただし水増しはしない）
- 1文40字前後、1段落3文まで。箇条書きは並列の項目にだけ使う
- 口調：15歳くらいの人に説明するつもりで、やさしく、ただし具体性は落とさない。数字・選手名・場面・「なぜそうなるか」の理屈を必ず入れ、「なんとなく」でごまかさない
  - 語り手は、落ち着いていて感情をあまり出さない、淡々と筋道立ててやさしく説明する案内役。文末は「〜なのだ」「〜というわけだ」「〜だ」を基本にする
  - 読み手には「あなた」と呼びかけてよい。たとえ話は身近なもの（じゃんけん、信号、行列など）を使い、最後に野球の話に戻す
  - モデルは『魔法少女まどか☆マギカ』のキュゥべえの話し方の「淡々と、筋道立てて、やさしく説明する」ところだけ。キャラクター名・決めぜりふ（「契約」「わけがわからないよ」など）・作品への言及は入れない。あからさまなキャラ口調にしない
- 野球用語を初めて出すときは、必ずかっこで言い換える（例：「併殺（ゲッツー：一度に2つアウトを取ること）」）
- 「今日の試合で見るなら」は必須。具体的な選手名や場面で書く（`data/today.md` を参照）
- 事実・数字は出典つき。出典がない、または 🔍 がついている項目の確認できない内容は書かず、`needs_check: true` にして `<!-- TODO: 確認 -->` を残す
- 個人情報（チケットの氏名・番号など）は書かない

## 「おもしろエピソード」の条件（厳守）

読んだ人が「へえ！」と誰かに話したくなる**話**を書く。情報の紹介ではない。

- 必須の3つ：**誰が**（実名の選手・監督・球団など）／**どんな場面で**（いつ・どこで）／**何が起きて、どうなったか**（意外な結末・名言・笑える一言・感動）
- 題材の探し方：その疑問のテーマにまつわる、歴代の名選手の逸話、珍プレー・珍記録、ルールや言葉が生まれたきっかけ、球場で起きた事件。今年や今日の話にこだわらなくてよい
- **書いてはいけないもの**
  - 数字や記録の紹介だけ（例：「西川は通算345盗塁。350まであと5」）→ 今日の話なら「今日の試合で見るなら」へ
  - 「しくみ」の言い換え・補足（例：「同じ1点でも作り方はいろいろある」）
  - 前日や最近の試合結果の報告（例：「9/27、寺地が先制の二塁打を放った」）
  - 公式記録やルールの細かい注記（例：「記録が訂正されることもある」）
- 見本（2-11「盗塁ってなに？」）
  - ✕ 日本ハムの西川遥輝は、9月27日終了時点で通算345盗塁。現役選手では最多で、通算350盗塁まであと5に迫っている。
  - ○ 盗塁の日本記録は、阪急の福本豊の通算1065個。1983年には当時の世界記録を抜き、国民栄誉賞の話まで持ち上がった。ところが本人は「そんなんもろたら、立ちションもできへんようになる」と断ったと伝えられている。
- 条件を満たす話が見つからなければ、見出しごと削除する（無理に書かない）。数字の紹介で埋めない
- 出典（記事・球団公式・NPB・Wikipedia など）を sources に書く

## 「今日の試合で見るなら」の条件
- 今日の試合で**どの選手の、どの場面を、どこに注目して見ればいいか**を書く。記録・数字の話（あと何本・何個など）はここに置く
- 「おもしろエピソード」と同じ内容を繰り返さない

## 見やすくするための装飾（必須）

- **太字**：`**…**`。初めて出てくる用語、覚えてほしい数字、選手名に使う。1段落に1〜2か所まで
- **黄色いマーカー**：`==…==`。その記事でいちばん覚えてほしい一文や、「今日見るならここ」という一句に使う。1記事に3〜6か所。マーカーの中に太字を入れてもよい（`==**…**==`）
- **画像**：見出しと見出しの間に1〜3枚はさむ。1行にこう書く
  `![何が写っているかの説明](https://upload.wikimedia.org/…/ファイル名.jpg "出典：Wikimedia Commons／作者名／ライセンス名")`
  - 使えるのは Wikimedia Commons（`upload.wikimedia.org`）にある、ライセンスが明記された画像だけ。Wikipedia の記事に載っている画像は、たいていここにある。URL は画像そのもの（.jpg / .png / .svg）を指すこと
  - NPB・球団・新聞・まとめサイトの写真は著作権があるので使わない（リンクを本文に書くのはよい）
  - 球場・道具・ルールの図・選手の写真など、本文の理解を助けるものを選ぶ。見つからなければ画像なしでよい（無関係な画像で埋めない）
