# 記事テンプレート（1問＝1ファイル）

置き場所：`content/<カテゴリ番号>/<ID>.md`（例：`content/1/1-07.md`、`content/1/1-07-a.md`）

```markdown
---
id: 1-07
title: SBOや青・黄・赤に光るあれは何？
category: 1            # question-tree.md のカテゴリ番号
level: 1               # 1 = トップのボタン、2 = 派生の疑問
priority: star         # star（★） / normal
needs_check: false     # 公式情報の確認が必要な記述があれば true
children: [1-07-a, 1-07-b, 1-07-c]   # level 1 のみ。この記事の下に出すボタン
related: [1-08, 4-01]  # 関連する別の疑問（任意）
sources:               # 数字や固有の事実を取った公式ページ・記事
  - https://npb.jp/
---

## ひとことで
（1〜2文。答えだけ）

## しくみ
（初心者向けに。専門用語は必ず言い換えを添える）

## 歴史・由来
（あれば。無理に書かない）

## おもしろエピソード
（1〜2個。出典があるもの）

## 今日の試合で見るなら
（2026/9/28 ロッテ×日本ハムで、どこを見ればこの知識が生きるか）
```

## 書き方のルール

- 読み手：野球をほぼ知らない大人。球場の待ち時間に、スマホで1〜2分で読む
- 長さ：level 1 は 300〜600字、level 2 は 150〜350字
- 1文40字前後、1段落3文まで。箇条書きは並列の項目にだけ使う
- 野球用語を初めて出すときは、必ずかっこで言い換える（例：「併殺（ゲッツー：一度に2つアウトを取ること）」）
- 「今日の試合で見るなら」は必須。具体的な選手名や場面で書く（`data/today.md` を参照）
- 事実・数字は出典つき。出典がない、または 🔍 がついている項目の確認できない内容は書かず、`needs_check: true` にして `<!-- TODO: 確認 -->` を残す
- 個人情報（チケットの氏名・番号など）は書かない
