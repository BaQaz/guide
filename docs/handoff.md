# 分担と受け渡しルール

## 分担
| 担当 | やること |
| --- | --- |
| Claude | 疑問ツリーと仕様の管理、今日の試合データ（`data/today.md`）、選手・監督カード（`data/players/` のロッテ全員・日本ハム先発とスタメン・両監督は作成済み）。利用量に余裕があるときに PR のファクトチェック |
| GPT | 記事本文（`content/`）の執筆（★の記事から優先）、日本ハムの残りの選手カード、🔍の記事（球団公式で確認できたものだけ）、サイトの実装 |
| 人間（オーナー） | 優先順位の決定、PRの最終確認とマージ、当日の気づきのフィードバック |

## GPTへの依頼単位（Issue）
締め切りは試合開始の 18:00 です。★を先に書き、それ以外は後日で構いません。

| Issue | 範囲 | 優先 |
| --- | --- | --- |
| #1 | カテゴリ1「野球ってそもそも？」の★（L1＋L2） | 最優先 |
| #2 | カテゴリ2「打つ・投げる・守る」の★ | 最優先 |
| #3 | カテゴリ4「数字・記録・スコアボード」の★ | 高 |
| #4 | カテゴリ5「今日の試合」のうち5-01〜5-06（`data/today.md` を必ず参照） | 高 |
| #5 | カテゴリ6「応援」 | 中 |
| #6 | カテゴリ3「選手の頭の中」 | 中 |
| #7 | カテゴリ2の残り・カテゴリ8 | 低 |
| #8 | 日本ハムの選手カード（スタメン候補・ブルペン・代打代走） | 高 |
| #9 | カテゴリ7「スタジアム」（🔍は球団公式で確認できたものだけ） | 高 |
| #10 | サイトの実装（スマホで読める静的サイト） | 最優先 |

2026/9/28 時点で Claude の利用量が少ないため、当初 Claude 担当だった #8〜#10 も GPT に任せます。Claude のレビューが間に合わない PR は、オーナーが PR 本文の出典一覧を見てマージしてよいことにします。

## ブランチとPR
- ブランチ名：`content/<Issue番号>-<短い名前>`（例：`content/1-basics`）
- 1つのPRで1つのIssueを扱う。PR本文には書いたIDの一覧と、`needs_check: true` にした箇所を書く
- `docs/question-tree.md` に疑問を追加・変更したいときは、記事と分けて別のPRにする

## ファクトチェックの基準（レビュー時）
- 数字・日付・記録は、出典URLの公式ページ（NPB・球団公式・主要紙）で確認できること
- 2026年の出来事は、GPTの学習データより新しい場合がある。出典のない2026年の記述は差し戻す
- 🔍の項目（イベント時刻・メニュー・持ち込みルールなど）は、球団公式の当日情報で確認するまで公開しない
