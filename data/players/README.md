## カードの書式
1人 = `##` 見出し1つ。見出しは `名前（#背番号、役割、投打、年齢）`。その下に次の7項目を必ずこの順で書く。

```markdown
## 名前（#00、ポジション、右投右打、00歳）
- 特徴：
- 見どころ：
- 出立ち：
- プロまで：
- プロで：
- 直近1年：
- 直近数試合：
```

公開情報が見つからない項目は「公開情報が見つかりませんでした」と書く（空欄にしない）。
